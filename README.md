## 📌 Overview

Multi-Modal Intrusion Detection System combining Machine Learning, NLP, and Explainable AI to detect network attacks with 98%+ accuracy.

## 🎯 Attack Detection

| Attack Type | Description |
|-------------|-------------|
| **DOS** | Denial of Service (SYN Flood, Ping of Death) |
| **PROBE** | Port scanning, network reconnaissance |
| **R2L** | Remote to Local unauthorized access |
| **U2R** | User to Root privilege escalation |
| **NORMAL** | Benign network traffic |

## ✨ Features

- ✅ Multi-class attack classification (5 types)
- ✅ Multiple ML models (Decision Tree, SVM, Random Forest)
- ✅ Multi-modal architecture (Network + NLP features)
- ✅ XAI with SHAP analysis
- ✅ SMOTE for imbalanced data
- ✅ Modern GUI dashboard
- ✅ Real-time anomaly detection
- ✅ Export results to CSV

## 📊 Performance
